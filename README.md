---

This repository also serves meilindagirsang.com through GitHub Pages.

| File | Purpose |
| --- | --- |
| `index.html` | The whole site, one page |
| `styles.css` | Styles, including dark mode and print |
| `main.js` | Marks the nav link for the section in view |
| `404.html` | Not-found page |
| `og.jpg` | Social preview card, 1200x630 |
| `CNAME` | Custom domain for GitHub Pages |

No build step. Edit the files and push to `main`; GitHub Pages publishes within a minute.
To preview locally, serve the folder over HTTP rather than opening the file directly,
so that root-relative paths resolve:

```bash
python3 -m http.server 8000
```
